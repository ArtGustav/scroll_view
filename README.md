# Scroll View

Aplicativo em React Native com Expo que busca e exibe uma lista de posts em uma área rolável. Cada post mostra seu identificador, título e um trecho do texto.

Os dados são carregados da API pública [JSONPlaceholder](https://jsonplaceholder.typicode.com/posts?_limit=8), limitada a oito posts.

## Requisitos

- Node.js e npm
- Expo Go no celular ou um emulador Android/iOS

## Como executar

```bash
npm install
npm start
```

Depois, escaneie o QR code exibido pelo Expo Go ou abra o projeto em um emulador. Para iniciar diretamente em uma plataforma:

```bash
npm run android
npm run ios
npm run web
```

## Tecnologias

- React Native
- Expo
- JavaScript
